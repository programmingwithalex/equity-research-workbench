# Equity Research Workbench

A personal financial-research application for comparing company filings and
building evidence-backed research reports, starting with TKO and APH.

## Status

Repository bootstrap only. Filing ingestion, retrieval, answer generation,
technical analysis, and portfolio scenarios are not implemented yet.

Development proceeds in small, explained increments through feature-branch pull
requests, automated checks, and versioned releases. Only public source material
and synthetic portfolio examples belong in Git; personal holdings and credentials
remain local.
